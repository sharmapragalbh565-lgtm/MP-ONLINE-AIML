## Projects

> Each project folder contains:
> - `README.md` — Project documentation and details
> - Source code / Jupyter Notebooks (`.ipynb`)
> - Model checkpoints and evaluation visualizations (`.png`, `.mp4`)
> - Render deployment link *(where applicable)*

---

### 1. Adult Census Income Classification
Classification model to predict whether an individual earns more or less than $50K/year based on census demographic features using machine learning algorithms.

---

### 2. Cancer Detection using MRI Images
An AI-powered cancer detection pipeline applying **Multiple Instance Learning (MIL)** on MRI image patches to classify and detect cancerous tissue.

---

### 3. Cifar-10 Image Classification using CNN
Deep learning computer vision model built using Convolutional Neural Networks (CNN) to classify images across 10 categories from the CIFAR-10 dataset.

---

### 4. End to End Render Deployment Project
A complete end-to-end machine learning project covering model training, REST API development using Flask, and live cloud deployment on **Render**.

---

### 5. Face Recognition using CNN in Wild Life (LFW Dataset)
A facial recognition system trained on the **Labeled Faces in the Wild (LFW)** dataset using CNN architectures for real-world identification and verification.

---

### 6. Movie Recommendation System
A personalized movie recommendation engine built using collaborative filtering and content-based filtering techniques to generate custom recommendations.

---

### 7. RAG Chatbot - Capstone Project (Render)
A **Retrieval-Augmented Generation (RAG)** based intelligent chatbot deployed on Render, combining Large Language Models (LLMs) with custom vector store knowledge bases for context-aware responses.

---

### 8. CartPole Control using Deep Q-Network (DQN)
A Reinforcement Learning (RL) agent developed using **Deep Q-Networks (DQN)** with experience replay and target networks to solve the OpenAI Gym / Gymnasium `CartPole-v1` balance control environment.

---

### 9. Lunar Lander Autonomous Landing using Deep Q-Network (DQN)
An autonomous Reinforcement Learning agent trained using **Deep Q-Learning (DQN)** to control spacecraft thrusters and achieve safe soft landings in the Gymnasium `LunarLander-v2` environment.
